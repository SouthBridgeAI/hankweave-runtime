# Primary Task

Please build a shim for the agent information provided in <%DATA_DIR%> and place it in <%EXECUTION_DIR%>/shim.

Please check the <%EXECUTION_DIR%>/shim for shim that has already been built. If one exists:

1. Initialize it properly.
2. Read the documentation thoroughly.
3. Review the code to understand what needs to be done next.
4. Continue.

If the shim is complete to the highest extent possible - the gold standard is built, researched, tested (passing the eval suite in @eval-suite) and documented - you may end.

## Task: Build and research

As you build the shim, perform additional research using the search tool (or subagents) as needed, and place results into `./research.md`. Also use `thoughts_questions_and_issues.md` as an append-only log for additional thoughts, questions and issues. In both files, keep an `END_OF_FILE` marker at the end that you can replace continuously as needed.
